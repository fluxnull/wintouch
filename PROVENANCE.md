# Provenance

WinTouch is a Windows-native `touch.exe` implementation inspired by BSD `touch` behavior.

No FreeBSD source file is redistributed as part of this repository.

Reference sources:

- FreeBSD touch source tree: <https://cgit.freebsd.org/src/tree/usr.bin/touch>
- FreeBSD `touch.c`: <https://cgit.freebsd.org/src/plain/usr.bin/touch/touch.c>
- FreeBSD `touch.1` manpage: <https://cgit.freebsd.org/src/plain/usr.bin/touch/touch.1>
- FreeBSD GitHub source mirror: <https://github.com/freebsd/freebsd-src>

WinTouch is an independent Windows-first Go implementation. If future code directly incorporates FreeBSD source material, the original FreeBSD copyright and license notices must be preserved in the affected files.
